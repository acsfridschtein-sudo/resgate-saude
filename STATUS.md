## Pendente

1. Criar um novo repositório na conta GitHub já autenticada.
2. Adicionar o repositório remoto ao projeto local.
3. Enviar a branch `main` ao GitHub.
4. Criar/importar o projeto no Netlify.
5. Publicar com um subdomínio temporário `*.netlify.app`.
6. Testar a URL pública em desktop e celular.
7. Configurar o número definitivo de WhatsApp antes da campanha.
8. Substituir a premissa provisória de 10% a.a. pelos índices validados pela equipe jurídica/atuarial.
